# Приёмка изменения модели

Навык ведёт изменение модели к состоянию, принятому прогоном входа: модель собирается, дельта
посчитана, решение по ломающим и разрушающим операциям получено от владельца.

## Границы

- Детерминированную работу выполняет вход `forge`: сборку — `forge build`, дельту — `forge diff`,
  нормы — `forge norms`. Навык не собирает дескриптор, не считает дельту и не пишет миграции сам.
- Файлы модели правит вызывающий — агент по просьбе владельца или сам владелец. Навык называет,
  что и по какой норме править.
- Навык **не выпускает** версию. Выпуск ведёт навык `forge:model-release`; его шаги здесь
  не повторяются.
- Нормы называются кодом и вызовом выдачи; текст норм в навыке не повторяется.

---

## Шаги

1. **Нужно ли изменение модели.** Сформулировать, что должно измениться в структуре: тип узла,
   поле, перечисление, сигнатура связи. Если задача решается без изменения модели — навык
   завершается, файлы модели не правятся.
2. **Нормы.** Получить нормы, которые затрагивает изменение, вызовом входа:
   - формат типа узла и поля — `MDL-006` (`forge norms --rule MDL-006`), `MDL-009`
     (`forge norms --rule MDL-009`);
   - сигнатура связи — `MDL-013` (`forge norms --rule MDL-013`);
   - занятые номера — `MDL-016` (`forge norms --rule MDL-016`);
   - разряды версии — `MDL-018` (`forge norms --rule MDL-018`);
   - удаление поля — `MDL-027` (`forge norms --rule MDL-027`), ввод обязательности — `MDL-028`
     (`forge norms --rule MDL-028`).

   Образец минимальной модели печатает `forge sample`.
3. **Правка модели.** Вызывающий вносит правку в файлы модели и повышает разряд версии
   по `MDL-018` (`forge norms --rule MDL-018`).
4. **Сборка.** Выполнить `forge build`. Код `1` — модель отвергнута: исправить названные
   нарушения и повторить шаг. Код `2` — ошибка вызова или окружения: устранить её, правку модели
   не трогать.
5. **Дельта.** Выполнить `forge diff` и разобрать операции по классам — `MDL-020`
   (`forge norms --rule MDL-020`). Код `1` — гейт совместимости: исправить по `MDL-025`
   (`forge norms --rule MDL-025`) и вернуться к шагу 4.
6. **Решение владельца.** Если дельта содержит операцию, ломающую контракт — `MDL-022`
   (`forge norms --rule MDL-022`), — или разрушающую данные — `MDL-023`
   (`forge norms --rule MDL-023`), — остановиться и назвать владельцу каждую такую операцию
   и норму, по которой она классифицирована. Без решения владельца изменение не принято.

## Исходы

| Исход | Условие | Что сообщить |
|-------|---------|--------------|
| Изменение не нужно | шаг 1 установил, что модель не меняется | причину; файлы модели не тронуты |
| Изменение принято | `forge build` и `forge diff` дали `0`, ломающих и разрушающих операций нет либо владелец их принял | дельту из вывода `forge diff`; выпуск — навыком `forge:model-release` |
| Ждёт владельца | дельта содержит ломающую или разрушающую операцию, решения нет | операции и нормы `MDL-022` / `MDL-023` |
| Отвергнуто | `forge build` или `forge diff` дали `1`, исправление не найдено | нарушения из вывода входа |
| Ошибка окружения | вход дал `2` | диагностику входа |
