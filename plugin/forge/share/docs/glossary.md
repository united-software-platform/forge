## Структура модели

| Понятие | Определение |
|---------|-------------|
| Модель (Model) | Описание структуры графа требований в файлах каталога `model/<пакет>.v<MAJOR>/`; единственный источник истины о структуре |
| Манифест (Manifest) | Файл `_manifest.yaml` модели: имя модели, версия, перечисления |
| Тип узла (Node Type) | Вид узлов графа с кодом, номером, русским и английским именами и полями; описывается отдельным файлом в `types/` |
| Код типа (Type Code) | Неизменная аббревиатура типа узла из заглавных латинских букв; префикс кода экземпляра |
| Код экземпляра (Instance Code) | Идентификатор узла вида `<КОД ТИПА>-NNN` |
| Поле (Field) | Атрибут типа узла с номером, именем, типом и обязательностью; идентичность поля — его номер |
| Перечисление (Enum) | Именованный набор значений с номерами, на который ссылается поле типа `enum.<имя>` |
| Сигнатура связи (Relation Signature) | Описание допустимой связи между узлами: номер, имя, домен `from`, кодомен `to`, кардинальности, ацикличность |
| Кардинальность (Cardinality) | Границы `min`/`max` числа связей у узла на одной стороне сигнатуры |
| Ацикличность (Acyclicity) | Требование отсутствия циклов по связи; по умолчанию истинно |
| Занятые номера (Taken Numbers) | Перечень номеров и имён полей, номеров и имён значений перечислений и кодов экземпляров, выданных однажды и не выдаваемых повторно; ведётся инструментом |

## Версия и дескриптор

| Понятие | Определение |
|---------|-------------|
| Разряды версии (Version Components) | Три части версии `X.Y.Z`: MAJOR — ломающее изменение контракта, MINOR — структура, PATCH — описания |
| Дескриптор (Descriptor) | Скомпилированное представление модели одной версии в JSON; дескриптор выпущенной версии лежит в `model/releases/` |
| Хеш дескриптора (Descriptor Hash) | Контрольная сумма `sha256` структурных элементов дескриптора; описания в неё не входят |

## Изменение и выпуск

| Понятие | Определение |
|---------|-------------|
| Дельта (Delta) | Перечень операций, переводящих последнюю выпущенную версию модели в рабочую; печатается `forge diff` |
| Классы операций (Operation Classes) | Разбиение операций дельты на безопасные, ломающие контракт и разрушающие данные; класс определяет предупреждение при выпуске |
| Безопасная операция (Safe Operation) | Операция, после которой потребители версии и данные остаются корректными |
| Ломающая операция (Breaking Operation) | Операция, нарушающая ожидания потребителей прежней версии контракта |
| Разрушающая операция (Destructive Operation) | Операция, удаляющая данные хранилища |
| Гейт совместимости (Compatibility Gate) | Проверка выпуска, останавливающая его на ошибках процесса: версия не повышена, версия понижена, номер выдан повторно |
| Выпуск (Release) | Запись миграций, дескриптора и записи реестра для новой версии модели; выполняется `forge gen` |
| Свёртка (Baseline) | Миграция, создающая схему модели целиком без истории; выпускается `forge gen --baseline` |

## Хранилище

| Понятие | Определение |
|---------|-------------|
| Миграция (Migration) | Неизменяемый файл SQL каталога `changelog/`, переводящий схему хранилища на шаг версии |
| Замыкающая миграция (Closing Migration) | Последняя миграция версии: записывает версию и хеш модели при условии, что в хранилище лежит хеш предыдущей версии |
| Отпечаток версии (Version Stamp) | Версия и хеш модели, записанные в хранилище замыкающей миграцией |
| Реестр выпусков (Release Registry) | Файл `changelog/registry.yaml` с перечнем выпущенных версий, файлов и их контрольных сумм |
| Запросы целостности (Integrity Checks) | Запросы SQL, проверяющие то, что схема не выражает: кардинальность и ацикличность; печатаются `forge checks` |
