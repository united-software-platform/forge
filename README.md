# Forge

**Модель → Схема**

Forge — кузница моделей данных: из описания модели она выковывает дескриптор, миграции хранилища
и вердикт о совместимости версий.

Модель описывается набором YAML-файлов и живёт в репозитории наравне с кодом. Forge превращает это
описание в проверяемые артефакты и следит за тем, чтобы очередная версия модели не сломала уже
существующее хранилище.

## Что делает

- **Собирает дескриптор** — сводит файлы модели в один нормализованный документ с версией и хешем.
- **Считает дельту** — сравнивает рабочую модель с последней выпущенной версией и называет изменения.
- **Держит гейт совместимости** — отличает безопасное изменение от ломающего и разрушающего.
- **Генерирует миграции** — выпускает changelog для PostgreSQL по вычисленной дельте.
- **Проверяет целостность** — печатает запросы контроля и сверяет фактическую схему хранилища с моделью.

## Быстрый старт

```bash
make init          # подготовка проекта: .env, каталоги, ключи, инструменты
make model-build   # дескриптор рабочей модели: версия и хеш
make model-diff    # дельта против последней выпущенной версии
make model-gen     # выпуск версии: миграции, дескриптор, запись в реестр
make model-test    # тесты инструментов модели
```

Полный перечень команд — `make help`.
