# Чек-лист соответствия

Порядок, которым агент проверяет целевой проект на соответствие образцу APB, перечень проверок
по решениям и форма отчёта. Требования и их основания — в [решениях](./decisions.md).

## Порядок проверки

1. **Сверить применимость** по [классификации](./index.md#классификация): оси «Тип»,
   «Исполнитель», «Среда исполнения» и «Модель работы» обязаны совпасть. Несовпадение —
   остановиться и назвать его владельцу: образец к проекту не применим.
2. **Сверить правила проекта:** коды, на которые ссылается спецификация, существуют в правилах
   проекта и означают то же. Расхождение кода — строка отчёта с исходом «расхождение правила».
3. **Пройти проверки** по таблице ниже, по порядку решений. Проверка прогоном предпочтительнее
   проверки чтением: где признак назван командой, команда выполняется.
4. **Не исправлять** по ходу проверки: проверка называет расхождение, исправление — отдельная
   работа после отчёта.
5. **Выдать отчёт** в [форме](#форма-отчёта).

## Исходы проверки

| Исход | Когда |
|-------|-------|
| Соответствует | Признак соответствия выполнен |
| Не соответствует | Признак не выполнен; в отчёте — факт и место |
| Неприменимо | Требование не относится к проекту по названной причине: например, у плагина нет зависимостей — нет и окружения |
| Расхождение правила | Код правила в проекте отсутствует или означает другое |
| Не проверено | Проверку нечем выполнить; в отчёте — чего не хватило |

## Форма отчёта

Отчёт — Markdown-документ по правилам документации проекта: заголовок, назначение, навигация,
таблица версий. Основная таблица:

```markdown
| № | Требование | Исход | Факт и место | Действие |
|---|------------|-------|--------------|----------|
| 18 | APB-004 (4) | Не соответствует | Сценарий `ExportUseCase` без контракта: `src/app/export.py:12` | Объявить контракт сценария |
| 14 | APB-003 (3), (4) | Неприменимо | Зависимостей нет — окружение не собирается | — |
```

После таблицы отчёт называет:

- итог: число проверок по каждому исходу;
- расхождения правил — коды и в чём расхождение;
- порядок исправления — по решениям, от [APB-001](./decisions.md#apb-001-поставка-плагином)
  к [APB-012](./decisions.md#apb-012-проверка-прогоном): поставка и слои раньше конвейера.
